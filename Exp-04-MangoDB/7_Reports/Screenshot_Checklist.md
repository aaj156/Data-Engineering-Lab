- [ ] MongoDB Version
- [ ] MongoDB Service Running
- [ ] Database Created
- [ ] Collection Created
- [ ] CRUD Output

- [ ] Python Connection

- Step01_Installation.png
- Step02_Server.png
- Step03_Database.png
...
